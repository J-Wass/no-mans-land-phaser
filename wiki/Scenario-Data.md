# Scenario Data (verbatim)

[← Back to Home](README.md)

This page reproduces the shipped scenario data exactly, so the scenarios can be rebuilt without the source tree. Narrative descriptions and the tutorial walk-through are on [Scenarios & Tutorial](Scenarios-and-Tutorial.md).

- `src/config/scenarios.json` — scenario definitions (schema in [Scenarios & Tutorial → Scenario file format](Scenarios-and-Tutorial.md#scenario-file-format)).
- `src/config/maps/*.terrain` — one 60×60 map per scenario. Legend: `W` water, `.` plains, `H` snow-forest, `F` forest, `M` mountain, `D` desert. Row 0 is the top line; column 0 is the first character.
- Map registry (`src/config/scenarios.ts`): `evershadow-tribe` → `evershadow.terrain`, `the-invaders` → `invaders.terrain`, `tutorial` → `tutorial.terrain`.
